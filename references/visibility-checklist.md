# Checklist de visibilidade do perfil LinkedIn

Os nomes dos menus mudam com o tempo. Se um item não estiver onde descrito, procure o equivalente em Configurações.

- [ ] Perfil público, com todas as seções visíveis para quem não é conexão.
- [ ] Setor (indústria) preenchido com o da área-alvo, para o LinkedIn saber a quais recrutadores te mostrar.
- [ ] Sinal de "disponível para trabalho": **só se a pessoa pode ser vista procurando emprego**. Se o empregador atual não pode saber, deixe desligado e não escreva "buscando vagas" no perfil.
- [ ] Mensagens abertas a recrutadores, para que contatos cheguem até você.
- [ ] Currículo disponível para recrutadores nas preferências de candidatura.
- [ ] Opção de compartilhar o perfil com o recrutador ao se candidatar ligada.
- [ ] Alertas de vaga criados para os cargos-alvo, com avisos de interesse às empresas quando o LinkedIn oferecer.
- [ ] Quem pode seguir você restrito a conexões, para que as pessoas se conectem em vez de só seguir.
- [ ] Feed ordenado por "mais recentes", para ver as vagas e posts logo que saem.
- [ ] URL personalizada do perfil, curta e com seu nome.
- [ ] Foto e banner coerentes com a área-alvo.
- [ ] Idiomas listados com o nível real de cada um.
